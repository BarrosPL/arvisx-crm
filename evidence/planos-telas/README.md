# Telas do plano: empresa restrita ao lado de empresa isenta

Commit `0033449e5` (09/11/2026, migration 9802). `restrito-` é uma empresa num plano com telas limitadas; `isenta-` é uma empresa sem restrição. Medidas em `restrito-medidas.json` e `isenta-medidas.json`.
