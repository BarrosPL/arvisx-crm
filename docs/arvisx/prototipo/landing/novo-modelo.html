Perguntas frequentes

O que costumam perguntar antes de fechar.

Quanto custa?

Plano único de €189/mês + IVA, com atendentes e números ilimitados. Os Agentes Arvisx são orçados em reunião. confirmar valor

Preciso saber programar?

Não. Conectar o WhatsApp e começar a usar o CRM não exige programação. ajustar ao cadastro

Existe limite de atendentes ou números?

Não há cobrança por atendente nem por número, dentro do uso justo de uma empresa por conta.

Funciona com o WhatsApp comum?

Sim, por QR code ou pela API oficial da Meta. O QR code é um canal não oficial, com risco de bloqueio como qualquer ferramenta desse tipo. Na API oficial, os custos são cobrados pela própria Meta. API oficial: verificar

Quem paga a IA?

Você, diretamente ao provedor que escolher, com teto mensal. Os Agentes Arvisx têm condições próprias, combinadas na reunião. verificar teto

O que são os Agentes Arvisx?

Agentes personalizados, integrados ao seu CRM, construídos pela nossa equipe depois de entender a sua operação. A contratação é por reunião.
