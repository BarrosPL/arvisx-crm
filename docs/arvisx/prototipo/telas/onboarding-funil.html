Onde ele organiza seus clientes

Cada cliente vira um cartão que anda por essas colunas. Ele mesmo move o cartão conforme a conversa avança — por isso cada coluna diz também quando ele deve usá-la.

Seu funcionário montou este quadro olhando o que você me contou sobre o negócio. Ajuste o que quiser.
  1. 1
    Ele move o cliente para cá quando acabou de chamar e ninguém respondeu ainda.
  2. 2
    Ele move o cliente para cá quando já foi respondido.
  3. 3
    Ele move o cliente para cá quando ele está entendendo o que a pessoa precisa.
  4. 4
    Ele move o cliente para cá quando já dá para saber o que oferecer.
  5. 5
    Ele move o cliente para cá quando está fechando preço, horário ou condições.
  6. 6
    Ele move o cliente para cá quando fechou negócio.
    obrigatória
  7. 7
    Ele move o cliente para cá quando não fechou.
    obrigatória
O que veio na instalação (Vendas)

Novo contato → Já respondi → Escolhendo o produto → Vai levar → Aguardando pagamento → Pedido pago → Não comprou

Este é o quadro padrão, feito para loja online. Ao continuar, ele é substituído pelo de cima.
